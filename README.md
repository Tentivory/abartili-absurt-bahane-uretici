# Abartılı Absürt Bahane Üretici

**DİKKAT: Bu repo insanlığın en büyük icatlarından biridir.**

Neden geç kaldın? Neden ödevini yapmadın? Neden toplantıya katılmadın? Artık bu sorulara cevap aramana gerek yok. Bu muhteşem, eşsiz, efsanevi Python scripti sana **gerçekten inanılmaz** absürt bahaneler üretir.

## Özellikler
- %100 çalışır (inanmıyorsan çalıştır)
- Tamamen Türkçe, tamamen saçma
- Hiçbir mantığı yoktur, zaten olmasın da
- Her çalıştırmada farklı bir felaket üretir

## Nasıl Kullanılır?
```bash
python bahane_uretici.py
```

Çıktı örneği: "Kedi benim klavyemi yedi, sonra pişman olup kusunca bilgisayarım kısa devre yaptı."

## Yasal Uyarı
Bu bahaneleri gerçek hayatta kullanırsanız sorumluluk tamamen size aittir. Biz sadece absürtlük üretiyoruz.
